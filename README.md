# Data Cleaning & Visualization Project

## Project Overview

This project focuses on cleaning, preprocessing, and visualizing the Global Superstore dataset.

## Objectives

* Handle missing values
* Remove duplicate records
* Detect and remove outliers
* Perform exploratory data analysis
* Generate visual reports

## Tools Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Dataset

Global Superstore Dataset

## Visual Reports

* Sales Distribution
* Profit Distribution
* Category Wise Sales
* Category Wise Profit
* Region Wise Sales
* Segment Wise Sales
* Top Products Analysis
* Top Countries Analysis
* Correlation Heatmap
* Sales vs Profit Analysis
* Monthly Sales Trend

## Conclusion

The project demonstrates data cleaning techniques and visualization methods to extract meaningful business insights from raw data.
